# Accepted direction and implementation rulings

- User chat takes precedence over `StackCorp_Spec`, which remains preserved.
- Godot 4.6.1 standard, GDScript, Compatibility. No .NET, npm, plugins, services or runtime network calls.
- Windows `Play.cmd` prepares an official portable Godot runtime once if absent. `project.godot` also runs with editor F5. Source must include all referenced assets.
- Three difficulties: Easy/Medium/Hard. Win-rate goals 80/50/30% are design targets, not measured outcomes.
- Backend is a local simulation, separate from presentation. Commands change state; the frontend never grants money or progression.
- Free card table with pan/zoom, floating edge HUD, shop and sell area; no production lanes or mandatory card-placement grid.
- English in-game text, mint/cream/ink handmade art, original garden exterior and bundled fonts/icons.
- Source saves live under Godot user storage; tutorial and new-run actions must not silently delete a previous run.
- A focused scenario suite and visual smoke pass replace exhaustive balance bot runs for this delivery.
